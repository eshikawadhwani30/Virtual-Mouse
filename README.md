# 🖱️ Virtual Mouse Using Hand Gestures

A computer vision-based Virtual Mouse that allows users to control the mouse cursor using hand gestures through a webcam.

The project uses **OpenCV** and **MediaPipe** to detect hand landmarks and **PyAutoGUI** to control the mouse cursor.

## 🚀 Features

- 🖐️ Real-time hand detection
- 🖱️ Control mouse cursor using the index finger
- 👆 Perform left-click using thumb and index finger gesture
- 📷 Webcam-based interaction
- ⚡ Real-time gesture recognition
- 🖥️ Works with the computer's mouse cursor

## 🛠️ Technologies Used

- **Python**
- **OpenCV** – Image and video processing
- **MediaPipe** – Hand landmark detection
- **PyAutoGUI** – Mouse control
- **Math** – Distance calculation between fingers
